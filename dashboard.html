System Documentation & Quickstart

Complete step-by-step setup manual for Project HoutarouBot

v3.1 READY
1 Gemini AI Key

Generate a free API key at aistudio.google.com. Paste it in the Configuration tab. It auto-retries on server busy (503/429) and falls back models smoothly.

2 Streamer.bot WebSocket

In Streamer.bot, go to Servers/Clients > WebSocket Server. Ensure it is listening on 127.0.0.1:9001 with auto-start enabled.

3 Streamer.bot Reply Actions

In Streamer.bot, actions named AI_Reply_Kick, AI_Reply_Twitch, and AI_Reply_YouTube route the AI responses back into chat via your bot account without authentication errors.

4 Audio Redemptions (!redeem)

Set actions in Minigames tab (e.g. sus:0, wow:25, ara:50). Viewers use !redeem sus or shorthand !sus to trigger the sound live!

5 OBS Studio Overlay

In OBS, add a Browser Source with URL http://localhost:8081/overlay.html (1920x1080). Neon cards popup on AI replies, rolls, and redemptions!

6 Chat Commands Cheatsheet

!bot [msg] • !points • !donate / !kofi • !gamble • !heist • !redeem [name]

7 Ko-fi Donations & Live Stream Alerts Setup
Option A: Simple Link (!donate in chat)

Put your Ko-fi link in Social Links above. When viewers type !donate or !kofi in chat, the bot instantly sends your link! No API needed.

Option B: Real-Time Live OBS Alerts (Free Webhook)

Go to Ko-fi > Settings > Webhooks. Set Webhook URL to http://<your-host>:8081/api/kofi-webhook. Live donations trigger neon screen alerts, chat thank-yous, and auto bonus points!
